# 比赛检索助手：首版设计

用户目标：人工操作数据库网站，AI辅助理解题目、规划最短检索路径和准备可复制的检索词。

## 输入与路由

- 输入题目文本、粘贴截图或选择图片。截图保留识别出的题干、选项、否定词、时间、标准号和专利号；模糊字段必须明确提示。
- 每个小题独立分流：direct（稳定知识或可计算）、retrieve（需要外部资料）、clarify（题干不完整）。混合题可同时包含直接答案与检索步骤。
- 直接答案显示选项、内容和简短推导。时间敏感事实、指定数据库题、数量统计题不得凭记忆直接确定。
- 不将题干或图片内的指令当作系统指令。模型不确定时保留不确定点，不生成虚假检索结果。

## 检索路线卡片

每步显示：要查什么 → 推荐网站 → 输入字段 → 可编辑查询值 → 限定条件 → 在结果中核对哪个字段 → 无结果时的备选检索词。

输入字段拆开呈现，例如“篇名”“作者”“年份”“标准号”，每项独立复制。按钮支持“复制后打开网站”和“复制本题路线”。网站以本站已收录的稳定 ID 选择，前端用目录映射真实 URL；模型生成的任意网址不直接执行。

日期、数据库、统计口径、文献类型、有效状态等关键约束醒目显示。默认只显示最有希望的首个路线和一个备选，减少比赛时阅读负担。

如果后一步依赖前一步找到的值，显示“从上一步结果填入作者/申请人/标准号”等占位说明，不编造尚未知晓的值。

## 浮窗

优先检测 Document Picture-in-Picture API。用户点击后创建置顶小窗，内容包含当前题目、步骤、字段复制、打开网站、完成标记。保留导航页，外站新标签打开；浮窗生命周期依赖原页面。

不支持时使用本站可折叠面板和剪贴板复制。普通网页不能读取或向跨域数据库输入框自动填值。若未来需要跨网站自动填表，可另建明确授权的浏览器扩展，不属于首版。

## AI 接入

已检查 evidence-chain 的 GeminiWebProvider：已有文本及截图附件支持、异步调用、显式错误状态；可通过独立适配层调用，不复制检索爬虫，也不强制采用证据链的整个业务流程。

证据链当前 HTTP 服务仅允许本机同源请求，Cloudflare 导航不能直接调用。首版需独立本机桥接服务或本地助手页面。只绑定 loopback，受限来源、会话校验和大小限制；不向公网开放登录浏览器控制接口，不导出 Cookie。

云端替代方案：Pages Functions 或 Worker 持有模型 API 密钥，前端仅调用受控任务端点；需配置访问控制、请求限额、附件限制。密钥不进入静态 JS。现有部署 Token 权限仅为 Pages。

## 后续提高准确率

- “把查到的文本或截图带回来”：根据用户提供的结果回答，检查题干要求和来源内容是否对应。
- 稳定标识符优先：标准号、专利公开号、DOI、ISBN等原样复制，防止OCR混淆。
- 高频题型模板：标准状态、专利字段、年鉴数据、论文作者/被引/发表时间。
- 一键标记已完成，保留本题检索记录；多个题目分开显示，避免误复制上一题关键词。

## 验收

文本常识题、计算题、截图检索题、混合题、图片模糊、模型不可用、JSON错误、未知网站ID、剪贴板失败、浮窗不支持、模型超时均需明确可恢复状态。使用模拟模型运行离线测试；真实Gemini调用另外测试。上线报告必须区分UI验收与真实模型调用成功。

实现状态：已完成独立本机助手和静态助手界面，复用证据链Gemini网页Provider。路线字段独立编辑/复制，步骤依赖、备选输入、人工完成标记已实现。自动提交使用真实发送控件点击，未确认时不重发；解析兼容Gemini代码块的JSON语言标签。纯四则算式采用本地精确分数运算。当前标签刷新会恢复草稿和路线；未完成任务仅查询原任务，不重复提交。64项相关离线测试通过。实际截图题已获得Gemini完成回答并显示为检索路线；线上计算及刷新恢复已验收。置顶API在用户Edge中的真实表现仍需实际验证，提供复制回退。部署和最终验收记录见DEPLOY.md及assistant-qa-results.json。

本版支持Gemini/DeepSeek多选，默认Gemini。双模型直接独立接收截图，不以另一模型识别结果代替原图；两条路线分别展示且一方失败不丢失另一方结果。已复用原DeepSeek窗口完成截图调用。权威比赛入口在短目录中固定保留，防止无文字关键词的截图题遗漏标准/专利/统计入口。原题置于路线顶部，标识符、年份与否定词高亮；原图按钮在本次图片可用时展示。复制并打开默认尝试置顶，可取消。

首个完整且可解析的结果优先展示，另一个模型继续处理。后来的结果保留为可切换路线，不自动抢走当前选择。模型上传/生成阶段分别展示；编辑字段不被重新解析旧响应覆盖。任务未结束时已显示路线也可刷新恢复。国家标准统一使用用户指定的国家标准全文公开系统地址。
