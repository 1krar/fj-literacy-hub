# 素养聚合 · 信息素养比赛检索工作台

网站：[fj-literacy-hub.pages.dev](https://fj-literacy-hub.pages.dev/) · [题目路线助手使用说明](https://fj-literacy-hub.pages.dev/assistant-guide.html)

集中整理学术、标准、专利、统计、法律及备赛资源，帮助使用者自己快速检索。题目路线助手默认使用 DeepSeek，支持文本和截图、Gemini / DeepSeek 双模型并行、先完成先显示、逐步复制与跳转、独立 AI 作答及核验提示、手动重试和错误报告。模型回答需要人工核验。

CTRL 助手支持连续收题：粘贴或拖入截图后默认自动建题并入队，一张图对应一道题；输入始终可用。顶部窄任务条可在主页面和置顶小窗切换题目，后台结果不会自动切走当前题。自动派单默认启用 DeepSeek、Gemini，每题只交给一个空闲模型；两者都忙时进入公共队列，先空闲的模型领取下一题，也可以只启用一个模型。

截图先回显原题，再在同一对话提取关键词和推荐网站；已收录链接使用本站目录，站外链接标“未收录”，建议不足时补充本站相关或上级入口。默认不自动问答案。勾选任务条右侧“自动问答案”后，新题会在生成检索建议的同一次回复中附带初步答案，并对需要数据库或实时信息的题提示待核验；已有题不受开关影响。“询问本题模型”沿用本题负责的模型，优先排队且不打断正在执行的请求。每题都有自己的原图、结果、时间、刷新、失败重试和错误报告。

最近20道题保留在本机服务内存中，页面刷新可恢复任务和原图；服务重启后清空。同时排队上限为20道题。完成的题可点击“归档”，移除卡片并清理助手创建的模型标签。提交失败保留截图，重试使用同一提交编号避免重复发送。进入：[CTRL 助手](https://fj-literacy-hub.pages.dev/launch-assistant.html?tool=ctrl)。

## Windows 本机助手

1. 下载仓库 ZIP 并完整解压，或 `git clone` 此仓库。
2. 安装 Python 3.12 或更新版本及 Microsoft Edge。Python 安装时勾选加入 PATH。
3. 双击根目录的 `安装一键启动.cmd`。选择 Y 可在登录 Windows 后后台预启动，选择 N 可关闭；两种选择都会为当前 Windows 用户注册 `literacy-assistant://open`。缺少 Playwright 时安装器会联网安装。
4. 从网站大标题打开新的 CTRL 助手标签；已预启动的服务会直接进入。服务未运行时在启动页点击原生“启动本机助手”链接，或双击 `启动比赛助手.cmd`。首次浏览器提示打开应用或访问本地网络时按需允许。
5. 在助手打开的 Gemini / DeepSeek 窗口登录你自己的账号。数据库网站使用普通 Edge 自己的登录状态。

本机路线助手地址：`http://127.0.0.1:8771/assistant.html`；CTRL 助手地址：`http://127.0.0.1:8771/ctrl-assistant.html`。网页服务只监听本机地址。请保持助手页打开，置顶小窗依赖该页面；CTRL 助手和题目路线助手的小窗都能直接粘贴文字或截图并提交，输入会同步回原页面。普通 Edge 的模型登录不一定与助手独立模型窗口共享；新设备首次需要在模型窗口登录。

仓库附带 `vendor/evidence-chain` 的两个网页 Provider 分发快照，独立下载即可使用；无需另行下载整个证据链项目。如果相邻目录有 `evidence-chain`，复用其既有模型浏览器登录配置，连接代码使用仓库分发快照。也可设置 `EVIDENCE_CHAIN_ROOT` 指定连接组件目录、`LITERACY_ASSISTANT_PYTHON` 指定 Python 的完整路径。移动项目后重新安装启动入口。

## 静态使用与其他设备

打开网站的静态助手，复制提示词到自己的模型网页，再把完整 JSON 回答导入显示检索路线；手机、平板也可使用此方式。Windows 自动启动入口无法调用另一台电脑的本机服务。截图支持 PNG / JPEG，最多 5MB。

## Cloudflare Pages 部署

`dist/` 是可直接部署的静态文件。使用 Node.js 和 npm：

```sh
npm ci
npm run build
npx wrangler login
npx wrangler pages project create your-project-name
npx wrangler pages deploy dist --project-name=your-project-name
```

也可以在 Cloudflare Pages 直接上传 `dist/`。静态导航和手动助手无需 API 密钥。本仓库现有 `npm run deploy` 和 `cf:*` 是作者本机的加密凭证工作流，其他用户按以上 Wrangler 流程部署即可；仓库不包含作者的账号配置和凭证。

部署自己的域名时，自动检测接口目前只允许 `https://fj-literacy-hub.pages.dev`；需在 `scripts/assistant_server.py` 中将生产来源改成自己的精确 HTTPS 域名，再重启本机服务。模型控制接口保持本机同源并校验会话，勿开放公共访问。不能自动检测时仍可手动启动并进入本机地址。

## 开发检查

CTRL 工作台将详细模型策略和 API 配置集中到“设置”，主页面及小窗保留各环节的“换模型复核”。识题从原截图独立识别，检索建议与答案从当前采用的原题独立生成，不把原答案发给复核模型。版本下拉可切换；新版本完成只提示，不自动切走当前结果。采用新的识题文本后，已有建议和答案标记“依据旧原题”，由用户决定是否重新生成。最多保留每环节最近 20 个结果版本，仍在本机内存保存。

重做失败步骤仍可从“⋯”展开，也可 **Shift＋点击重试** 或 **Alt＋Shift＋Enter** 直接触发。快捷键仅在助手主页面或置顶小窗有焦点时生效；不会接管其他网站上的输入。普通重试优先读取完整回复；重做会重新请求失败环节。一个环节失败后，其他环节成功不会移除它的重试入口。

CTRL 助手采用统一任务工作台，默认 API 模式。全局最多同时执行 6 个 API 请求；只选千问时可使用全部 6 个位置，书生与千问共享上限。网页模式继续每模型一个串行通道。每个环节默认只调用一个模型，不自动把一道题发给多个模型。手动问答案与重试优先处理，不打断已发送请求。“自动问答案”默认关闭。

默认千问一次流式请求识别原题并给出关键词和网站，完整原题字段先显示，不等待整份建议。高级设置可分别指定 OCR 和检索建议模型；不同模型时先识题再发送识别文本。原题下方和置顶小窗可临时选择答案模型，“千问思考”仅影响千问作答。答案使用本题自己的输入，不覆盖检索建议。API 限流、网络中断不自动重发；手动重试先尝试解析已经保存的完整回复。

“书生 API 设置”预设 `https://discovery-api.intern-ai.org.cn/v1`。填写自己的 Key 后启用。OCR 下拉仅列出支持图片的模型；文本建议/答案可选择 DeepSeek Flash 等文本模型。书生思考参数使用平台默认，不假设支持千问的关闭思考参数。书生 Key 同样可由 Windows DPAPI 加密保存在本机 `.runtime`。设置改变只影响新题，已经排队的题保留提交时配置。

阶段、总耗时、请求并发与排队数分开显示；没有服务器进度信息时使用阶段指示，不显示虚构百分比。API 返回的实际模型、请求耗时和 token 用量由后台保留，不估算未知费用。免费额度按各账号和平台实际规则，软件不将其视为无限额度。

主页面和置顶小窗的任意内容区域均支持 Ctrl+V 粘贴截图及拖图；连续图片各新增一题，不覆盖当前题，也不自动切换正在查看的卡片。重试优先读取原对话；读取失败时，可在重试旁的“⋯”选择重新执行失败步骤。

在本机 CTRL 助手展开“千问 API 设置”，地址已预设为 `https://maas.qianwenaiapi.com/compatible-mode/v1`；填写 API Key 即可保存，并将 `qwen3.8-flash` 加入派单。使用百炼业务空间或其他地域的 Key 时，可将地址改为控制台提供的地址；完整的 `/chat/completions` 接口地址会自动转换为 Base URL。Key 不回传到前端；可选择用 Windows DPAPI 在 `.runtime/qwen-config.dpapi` 加密记住。不记住则仅当前服务进程保留。也支持 `LITERACY_QWEN_API_KEY`、`LITERACY_QWEN_BASE_URL` 环境变量。API 请求使用流式回复，默认关闭思考模式；中断或截断不会当作完整结果，也不会自动重发。

目前 API 功能仍由本机服务调用。静态页面不能保存或使用凭证，手机云端自动调用将在后续加入独立的后台服务。

```sh
npm test
python -B -m unittest discover -s tests -p test_assistant_server.py
python -B -m unittest discover -s tests -p test_start_assistant.py
```

`npm run build` 使用已整理的资源和收藏夹 JSON，不需要原始 PDF。历史资料导入脚本需要自己的源文件，不属于正常安装步骤。
